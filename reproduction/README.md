# Model and local analysis code

Frozen scientific source, independent full-pipeline launchers, protocol settings and analysis/plotting programs are supplied. Running the configured tasks creates a new local output folder. Input/source fingerprints and component flags remain fixed, with no historical output overwrite. The portable protocol resolves local dataset paths and receives a new bookkeeping fingerprint.

No experiment output archive, score table, result figure, scientific results supplement or reviewer-response letter is included. Dataset construction documentation is ../docs/DATASET_CONSTRUCTION.md. Procedures are described in ANALYSIS_PLAN.md; metric units are in ../docs/METRICS.md.
